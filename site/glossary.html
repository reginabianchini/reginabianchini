"Glossary"

"HTML"
HyperText Markup Language, the standard language for creating web pages
"Header"
Contains meta-information about the page such as title and links to stylesheet
"Body"
Holds all the visiable content of the web page such as text,images, and links.
p
Defines a paragraph of text inside the body of the page
"hr" or "br"
Defines a break in an HTML page. "hr" creates an horizontal line. "br" skipps a line. No closing tag required, because it is an empty tag.
